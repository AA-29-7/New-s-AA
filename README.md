# New AA's

Interface privée de couple centralisant plusieurs mini-apps (Habitudes, Carnet
de voyage, Journal, Bobine de film). Construite en React + Vite + TypeScript,
avec Firebase (Authentication + Firestore) comme backend, sur offre gratuite.
Les données personnelles ne sont jamais commitées dans ce dépôt (voir
`.gitignore`). Voir `docs/decisions.md` pour l'historique des choix techniques.
